# Books_Database_Analisis_de_libros
Books Database — Análisis de una base de datos de libros

# Contexto y problema.
En este proyecto trabajé con una base de datos relacional de una plataforma de libros. El objetivo era utilizar SQL para explorar información sobre libros, autores, editoriales, reseñas y calificaciones.

El reto consistió en extraer información relevante a partir de diferentes tablas relacionadas y utilizarla para responder preguntas analíticas.

# Mi contribución.
Realicé consultas SQL para explorar y analizar la información disponible en la base de datos.

Trabajé con diferentes tablas y relaciones, utilizando filtros, agrupaciones, funciones de agregación y operaciones de combinación para obtener los datos necesarios.

# Proceso y decisiones:
* Exploré la estructura de la base de datos y las relaciones entre las tablas.
* Identifiqué las variables necesarias para responder cada pregunta de análisis.
* Utilicé JOINs para combinar información de diferentes tablas.
* Apliqué funciones de agregación como COUNT, AVG y MAX.
* Utilicé agrupaciones y filtros para obtener métricas específicas.
* Analicé información relacionada con publicaciones, autores, editoriales, reseñas y calificaciones.

# Resultado y aprendizaje
El proyecto permitió obtener diferentes indicadores sobre el catálogo de libros y el comportamiento de las reseñas y calificaciones.

El principal aprendizaje fue fortalecer mi capacidad para trabajar con bases de datos relacionales y SQL, especialmente para transformar preguntas de negocio en consultas estructuradas y obtener información relevante de múltiples tablas.

Herramientas: SQL · PostgreSQL · Data Analysis
